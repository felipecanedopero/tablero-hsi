# Tablero

Página de una sola pieza, sin servidor ni dependencias. Se pega un texto que viene
ordenado en bloques y lo parte en tarjetas, cada una con su botón de copiar, para
pegarlas de a una en los campos de un formulario.

Formato que entiende:

```
=== AVISO ===
texto que se muestra pero no se copia

--- Nombre del campo ---
texto que se copia con un botón
```

Todo corre en el navegador. La página no envía ni guarda nada; al cerrar la pestaña
no queda nada.
